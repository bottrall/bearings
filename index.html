bearings

A themeless docs engine: plain markdown guides in, a checked static site and llms.txt out.

  • Guides are plain markdown that reads the same on GitHub.
  • The manifest is the only list of what exists.
  • If the check passes, the site is correct.

bearings has no theme. Your repo writes the layout; bearings builds the pages, a markdown copy of each, llms.txt and a search index, and checks every link, anchor, example, constant, image and diagram in them. This site is built by bearings from its own repo.
