Plain markdown in. A checked site out.

bearings turns the guides in your gem’s repo into a static site, a markdown copy of every page and llms.txt, then checks every link, anchor and example in them.

Start with Getting started

You write

$ bundle exec rake docs

bearings writes

Then it checks what it built

Every link, anchor, code example, constant name, image and diagram in the guides. If the check passes, the site is correct.

The guides

  1. Getting started Start here Install bearings, add the two Rakefile lines and build a first site
  2. The manifest Building a site Every manifest key, its default, and the problems a wrong one reports
  3. The layout Building a site The layout contract, what each template is given, and the files beside it
  4. Diagrams and images Building a site Mermaid diagrams and images in a guide, on GitHub and on the site
  5. The outputs Reference Every file a build writes into _site/
  6. The checks Reference Every problem a build or a check reports, and how to fix it
